An Arduino Mega-based automatic garage gate system that uses a motion sensor, keypad, ultrasonic sensor, servo motor, LCD, LEDs, and buzzer to create a password-protected automated garage entrance. The system detects motion, prompts the user for a password using a keypad, opens the garage gate when the correct password is entered, and automatically closes the gate after the vehicle passes.

HARDWARE:
Arduino Mega 2560
PIR motion sensor
4×4 membrane keypad
HC-SR04 ultrasonic sensor
Servo motor
16×2 LCD
Green LED
Red LED
Buzzer
Resistors
Breadboard
Jumper wires
