# Private Garage

An Arduino Mega-based mini automatic garage gate system that uses a keypad, ultrasonic sensor, servo motor, LCD, LEDs, and buzzer to create a password-protected automated garage entrance. The system detects motion, prompts the user for a password using a keypad, opens the garage gate when the correct password is entered, and automatically closes the gate after the vehicle passes.

# HARDWARE

* Arduino Mega 2560
* 16×2 LCD display
* 4×4 membrane keypad
* HC-SR04 ultrasonic sensor
* Servo motor
* Buzzer
* Green LED
* Red LED
* Breadboard
* Potentiometer
* Jumper wires
* USB cable
* 5V power supply
